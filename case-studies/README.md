# Case Studies

This section walks through complete system designs end to end — the closest analog to what you'll actually do in a system design interview. Each case study applies patterns from across the handbook to a realistic product scenario.

## Case Studies

- [E-commerce Platform](e-commerce-platform.md) - Catalog, cart, checkout, payments, and inventory at scale
- [Real-time Chat System](real-time-chat.md) - Messaging, presence, and offline delivery

## How to Use These

1. Read the problem statement, then **design it yourself first** on paper
2. Compare your design against the walkthrough — note what you missed
3. Study the trade-off discussions, not just the final architecture
4. Revisit after a week and redesign from scratch to test retention
